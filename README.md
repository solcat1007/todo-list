# 待办清单 (Todo List)

简洁高效的待办事项管理工具，支持分类筛选和本地持久化存储。

## 功能

- **添加任务**：输入待办事项，回车或点击添加
- **标记完成**：点击圆形复选框切换完成状态
- **删除任务**：点击 × 删除不需要的事项
- **三档筛选**：全部 / 未完成 / 已完成，一键切换
- **统计信息**：底部显示总任务数和已完成数
- **数据持久化**：使用 localStorage 保存，关闭浏览器不丢失
- **Canvas 背景**：动态网格背景装饰
- **中英文切换**：界面支持中文/英文
- **全屏模式**：点击"开始"进入全屏

## 使用方法

1. 用浏览器打开 `index.html`
2. 在输入框中输入待办事项，回车或点击"添加"
3. 点击圆形按钮标记完成/取消完成
4. 使用顶部筛选按钮切换视图
5. 点击 × 删除任务

## 技术栈

纯 HTML/CSS/JavaScript，localStorage + Canvas。
