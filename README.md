# 待办清单 (Todo List) v2.0

支持优先级、标签、拖拽排序与完成统计的本地待办工具。

## 🆕 v2.0 更新

- 新增 **分类标签**：生活 / 工作 / 学习 / 其他，可筛选
- 新增 **三维筛选**：完成状态 + 标签 + 优先级组合过滤
- 新增 **拖拽排序**：拖动 ☰ 手柄调整顺序，也支持 ↑↓ 按钮（触屏友好）
- 新增 **完成统计**：进度条 + 全部 / 已完成 / 剩余三项计数
- 注入 SOLCAT 彩蛋引擎，UI 全面美化

## 功能

- **添加任务**：输入内容，选优先级与标签，回车或点 `+` 添加
- **三档优先级**：高 / 中 / 低，默认按未完成 → 优先级 → 时间排序
- **标记完成 / 删除**：点击复选框切换状态，`×` 删除单条
- **清除已完成**：一键清理已完成任务
- **本地持久化**：数据保存在 localStorage，关闭浏览器不丢失
- **中英文切换**：界面与标签文案同步切换

## 使用方法

1. 打开 `index.html`
2. 输入待办内容，选择优先级与标签，回车添加
3. 用筛选按钮切换视图，拖动 ☰ 调整顺序
4. 顶部进度条实时显示完成率

## 🥚 彩蛋秘籍

| 操作 | 效果 |
|------|------|
| ↑ ↑ ↓ ↓ ← → ← → B A | 全屏彩带烟花 |
| 连点标题 5 次 | 开发者模式面板 |
| 输入 `solcat` 后回车 | 赛博朋克隐藏主题 |
| Ctrl + Shift + T | 切换赛博朋克主题 |

**本作专属**：解锁任意彩蛋后，清单里会自动出现隐藏任务「☠ 找到彩蛋了！」。

## 技术栈

纯 HTML / CSS / JavaScript，localStorage + Service Worker。用户文本统一用 `textContent` 渲染，防止 XSS。
